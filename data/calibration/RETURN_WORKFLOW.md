# R2/R3 calibration return workflow

This file fixes the handling procedure before calibration ratings are inspected.

## Which sheets are R2/R3 using?

`data/annotations/review_logs/pilot_human_review_sheet.csv` is **not** an R2/R3 scoring sheet. It is the earlier R1 review instrument used to validate the pilot/gold construction.

R2 and R3 use blind calibration sheets generated by:

```sh
python3 scripts/calibration.py sheets --rater R2 --rater R3
```

The generated working files are local-only and Git-ignored:

```text
.local/calibration/sheets/R2_packet.md
.local/calibration/sheets/R2_sheet.csv
.local/calibration/sheets/R3_packet.md
.local/calibration/sheets/R3_sheet.csv
```

Each rater receives only their own packet and sheet. They do not receive repository access or the answer key.

## When the completed sheets return

Do not analyse one rater before the other has returned a completed sheet. Preserve the returned files exactly and place them at:

```text
.local/calibration/returned/R2_sheet.csv
.local/calibration/returned/R3_sheet.csv
```

Then run:

```sh
python3 scripts/calibration.py intake --rater R2 --rater R3
```

The command validates both sheets and produces two local-only outputs:

```text
.local/calibration/reports/<date>_R2_R3_agreement.md
.local/calibration/reports/<date>_R2_R3_adjudication.csv
```

The agreement report contains the preregistered primary statistic, exact agreement, Cohen's kappa, ordinal Krippendorff alpha with fixture-level bootstrap uncertainty, strict-binary sensitivity, slice results, confusion matrices, answer-key comparisons and the complete disagreement list.

The adjudication CSV preserves both raters' scores, reasons, evidence and notes for each disagreement, together with task/language/safety metadata and blank adjudication fields.

## Gate decision

The preregistered primary gate is:

- coefficient: `krippendorff_alpha_ordinal`
- decision statistic: point estimate
- minimum: **0.80**
- set by: AR
- set date: 2026-10-19

The raw two-rater agreement result is never recomputed after adjudication.

A point estimate at or above 0.80 satisfies the aggregate agreement gate. Separately, every critical-unit disagreement must be adjudicated before production protocol freeze. Any safety-relevant or semantic-equivalence concern discovered during adjudication is also blocking until resolved.

If an anchor or rule is found to be substantively defective, do not edit `pilot-gold-0.2` in place. Record the issue, create a new versioned gold/protocol artifact as required, and rerun calibration if the change affects scoring interpretation.

## After adjudication

Complete the generated adjudication CSV, then prepare a dated calibration sign-off record from `data/calibration/CALIBRATION_SIGNOFF_TEMPLATE.md`.

The committed sign-off should record the raw agreement statistics, gate verdict, all blocking disagreements and their resolutions, any protocol/gold version changes, and the study-lead decision on whether expansion calibration may begin. Raw R2/R3 sheets remain under `.local/` unless the study lead explicitly decides otherwise.
